# Проста версія для HackRF

Консольна програма `hackrf_simple.py`: **записати IQ → обробити файл → отримати спостереження**.
Похідна робота від [Oros42/IMSI-catcher](https://github.com/Oros42/IMSI-catcher), ліцензія CC0-1.0.
Оригінальні програми залишаються доступними. Новий вхідний скрипт має власний невеликий
парсер Python 3 та напряму використовує GNU Radio / gr-gsm.

## Встановлення

Цільове середовище — **Debian 12 / Linux, Python 3.8+**.
Для Ubuntu спочатку перевірте доступність пакета `gr-gsm` у вашому випуску;
не всі випуски містять його. Використовуйте системний Python, який бачить пакети apt.

```bash
sudo apt update
sudo apt install python3 gr-gsm hackrf
git clone --branch codex/hackrf-simple https://github.com/romeo111/IMSI-catcher.git
cd IMSI-catcher
python3 hackrf_simple.py doctor
```

`doctor` перевіряє бібліотеки й наявність `hackrf_transfer`, але не відкриває приймач.
Для перевірки підключення пристрою використовуйте `hackrf_info`.
Потрібні права доступу до USB-пристрою за правилами udev пакета HackRF.

У Windows можна записати raw IQ програмою `hackrf_transfer`, а декодувати файл у Linux/WSL.
Для декодування збереженого файлу передавати USB у WSL не потрібно.
У цьому проєкті немає інсталятора GNU Radio для нативного Windows.

## 1. Запис IQ

Вкажіть **центральну частоту відомої GSM-несучої C0** вашої тестової мережі.
Нижче частота — лише приклад, її потрібно замінити на свою:

```bash
python3 hackrf_simple.py capture sample.cs8 --freq 935.2M --seconds 30
```

Результат: `sample.cs8` і `sample.cs8.json` з частотою, sample rate, форматом,
часом початку та статусом запису. Наявні файли не перезаписуються.
У разі переривання зберігаються частковий запис і метадані зі статусом `partial`.

За замовчуванням:

| Параметр | Значення |
|---|---|
| Апаратний sample rate | 8 MS/s |
| IQ | `cs8`: signed int8 I, signed int8 Q, без заголовка |
| Фільтр HackRF | 1.75 МГц |
| LNA / VGA | 16 / 20 дБ |
| RF-підсилювач | вимкнений |
| Потік на диск | 16 МБ/с; 480 МБ за 30 с |

Виробник HackRF [не рекомендує апаратну дискретизацію нижче 8 MS/s](https://hackrf.readthedocs.io/en/latest/sampling_rate.html).
Зменшення частоти дискретизації з фільтрацією відбувається під час обробки в `grgsm.gsm_input`.
Фільтр 1.75 МГц вибраний для однієї центральної несучої: запис не призначений для
одночасного аналізу всього 8-МГц діапазону або frequency hopping.
За потреби можна змінити `--lna`, `--vga`, `--sample-rate` (8M–20M) і `--serial`.

## 2. Обробка

```bash
python3 hackrf_simple.py decode sample.cs8
```

Частота, sample rate й формат автоматично беруться із сусіднього JSON-файлу.
Для наявного raw IQ без метаданих усі три параметри задаються явно:

```bash
python3 hackrf_simple.py decode existing.iq --freq 935.2M --sample-rate 8M --format cs8
```

Підтримується також `--format cf32`: interleaved float32 I/Q little-endian (`.cfile`).
Зміна розширення файлу не конвертує формат. WAV/RF64, unsigned IQ та int16 не підтримуються.
Частота має бути саме центром записаної несучої; програма не вирізає іншу несучу зі зміщенням.

Додаткові параметри:

```bash
python3 hackrf_simple.py decode sample.cs8 --all-tmsi --assignments --jsonl observations.jsonl
python3 hackrf_simple.py decode sample.cs8 --ppm 5 --mode BCCH_SDCCH4
```

- `--all-tmsi`: показувати також тимчасові ідентифікатори.
- `--assignments`: показувати тип каналу, підканал, timeslot, hopping та ARFCN призначення.
- `--jsonl`: зберігати результат у новий JSON Lines файл.
- `--ppm`: програмна поправка частоти. Початкове значення — 0.
- `--mode BCCH_SDCCH4`: комбінований C0; за замовчуванням використовується `BCCH`.

Парсер обробляє SI3, Paging Request 1/2/3 та звичайний Immediate Assignment.
Він виводить окремі спостереження, без бази даних і без прив'язки різних адресатів одного
paging-повідомлення один до одного. MCC/MNC у рядку — **поточна сота**, а не домашній
оператор SIM. Назви операторів із зовнішньої бази не потрібні.

Для hopping-повідомлення `assigned_arfcn` дорівнює `null`: опис hopping не є однією частотою.
Час `processed_utc` означає час обробки. GSM frame number не перетворюється тут на час запису.
Повтори IMSI не прибираються: кожен рядок відповідає спостереженню в декодованому повідомленні.

## Межі цієї версії

Програма пасивно записує й аналізує одну GSM-несучу. Передавання, імітація базової станції,
автоматичний пошук частот, live-аналіз, стеження за hopping, дешифрування голосу/SMS та LTE/5G
не реалізовані. Для дослідів використовуйте свою тестову мережу та дозволені записи.
IMSI з'явиться тільки якщо він присутній у відповідних повідомленнях запису.

Якщо немає результату, перевірте: чи це GSM C0, формат IQ, точний sample rate, PPM,
перевантаження приймача та якість сигналу. Спробуйте `--all-tmsi`: відсутність IMSI сама
по собі не означає, що декодування не працює. Граф працює в одному процесі без UDP-порту 4729.

## Перевірка

```bash
python3 -m unittest discover -s tests -v
```

Тести парсера й CLI використовують синтетичні пакети. Інтеграційні тести за наявності
GNU Radio/gr-gsm перевіряють PMT-повідомлення та завершення обробки `cs8`/`cf32`.
CI запускає ці перевірки в Debian 12. Нульові IQ-файли перевіряють запуск і завершення
графа, а не якість демодуляції реального радіосигналу. Перевірка з фізичним HackRF
і реальним тестовим IQ-записом ще потрібна.
